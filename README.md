# JavaScript Learning Notes 📘

Repo tổng hợp kiến thức JavaScript, học từ [MDN](https://developer.mozilla.org/en-US/docs/Web/JavaScript) và [W3Schools](https://www.w3schools.com/js/).

## 📂 Cấu trúc

```
├── notes/          # Ghi chú lý thuyết theo chủ đề (.md)
├── examples/        # Code ví dụ chạy được, tương ứng với từng ├── note
├── template.md      # Mẫu format cho 1 file note mới
├── package.json     # Cấu hình chạy code ví dụ bằng Node
├── tsconfig.json    # Cấu hình TypeScript (nếu viết ví dụ bằng .ts)
└── .gitignore
```
